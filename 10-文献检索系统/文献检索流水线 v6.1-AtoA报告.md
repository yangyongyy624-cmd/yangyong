### 核心设计原则

| 原则 | 说明 |
|------|------|
| **第一性原理** | 从临床问题出发，非从药物/关键词出发 |
| **质量优先** | 期刊评分 + 被引次数 + 年份加权 |
| **本地优先** | Obsidian 知识库已有全文的优先标记 |
| **强制验证** | 输出 PMID 列表，要求 Agent 引用原文详情 |
| **透明度** | 所有 API 输出保存到 /tmp，可追溯验证 |

## 三、去重与评分系统

### 3.1 去重策略

```python
1. DOI 去重：相同 DOI = 同一篇
2. PMID 去重：相同 PMID = 同一篇
3. Title 去重：相同标题 = 同一篇
4. 过滤公开数据集条目
```

### 3.2 评分模型（满分 65 分）

| 项目 | 最高分 | 评分标准 |
|------|--------|---------|
| 期刊影响力 | 25 | Tier20(IF>20)=25, Tier15(IF>10)=15, Tier10(IF>5)=8 |
| 被引次数 | 20 | >500=20, >200=18, >100=15, >50=12, >20=10, >5=7 |
| 年份 | 10 | ≥2025=10, ≥2023=7, ≥2020=5, ≥2015=3 |
| 本地验证 | 5 | Obsidian 知识库已有 |
| 指南加成 | 5 | Guideline 来源文献 |

### 3.3 评级标准

| 评分 | 标签 | 含义 |
|------|------|------|
| ≥32 | 🔴 高 | 顶刊 + 高被引 + 近 3 年 |
| 25-31 | 🟡 中 | 权威期刊 + 中等被引 |
| <25 | ⚪ 一般 | 普通期刊或低被引 |
